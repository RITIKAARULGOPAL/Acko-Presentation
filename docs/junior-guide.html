01The big picture

What we're making, why it needs your help, and what each team hands over.

What are we making?

We're making an interactive presentation for Acko's new office. It opens in a web browser like a website but works like a slideshow. Each time the presenter presses the arrow key, something happens on screen:

  • the empty floor draws itself, line by line;
  • red arrows show how people would escape in a fire;
  • the floor divides into six coloured neighbourhoods (one per team) around a shared Town Square;
  • the flat plan tilts up into a 3D view, then the 3D view separates into floating layers;
  • clicking any room opens its render, in a light and a dark version.

Why does this need your help?

A person looks at a drawing and understands it straight away. A computer can't "see" a drawing like that. It reads the information inside the file: which layer a line sits on, whether a shape is closed, what text sits inside it.

So if you draw a closed shape on a layer called PRES-NBHD and write N1 INDIRANAGAR inside it, the computer understands: this area is the Indiranagar neighbourhood. Now it can colour it, show its name, measure its area and count the desks inside it, all by itself.

Think of it likeLabelling boxes before moving house. The movers don't open each box to guess what's inside. They read the label and carry the box to the right room. Your job is to put clear labels on the drawing, so the computer puts everything in the right place.

Why it's worth the effort

Once the files are set up this way, every number in the presentation (areas, desk counts, escape distances) comes straight from your drawing, so it is always right. If the design changes, we simply re-export with the same names and the presentation updates. Nobody retypes numbers by hand.

02Words you'll hear

The handful of terms used in this guide and the spec, in everyday language.

DXF
A file type AutoCAD can save to. It holds the same lines, layers and blocks as a DWG, but other programs can read it. We can't open DWG files, so we ask for DXF.
Layer
Like a sheet of tracing paper inside the drawing. Every line sits on one layer. We use layer names to know what a line is.
PRES layer
A new layer you add only for the presentation. Their names all start with PRES-.
Polyline
A line made of several connected pieces, drawn with the PLINE command. AutoCAD treats it as one object.
Closed polyline
A polyline whose end joins its start and which AutoCAD has marked as "closed". Only closed shapes can be coloured and measured.
Label
A piece of text placed inside a shape to say what it is, such as MEETING 8.
Block
A saved bundle of lines that acts as one object, like a desk or a chair. We count blocks to count furniture.
Model space
The main drawing area in AutoCAD, as opposed to the printable sheet layouts.
Z = 0
Everything lying flat at floor level. Lines sometimes get a height by accident; the FLATTEN command fixes that.
Xref
Another drawing linked into yours. "Binding" it copies it into your file permanently, so nothing goes missing.
Axo (axonometric)
A 3D view looking down at an angle, where things don't get smaller in the distance.
Perspective vs parallel
Perspective is how our eyes see: far things look smaller. Parallel projection keeps sizes the same everywhere. We need parallel.
Group (SketchUp)
A bundle of objects that moves and hides together, like a folder.
Tag (SketchUp)
SketchUp's version of a layer. Switching a tag off hides everything carrying that tag.
Scene (SketchUp)
A saved camera view and set-up, shown as a tab along the top of the screen.
Export
Saving a picture or file out of SketchUp or AutoCAD.
PNG and JPG
Picture file types. A PNG can have a see-through background; a JPG can't.
Transparent background
The empty part of the picture is see-through, so pictures can be stacked on top of each other.
Pixels (px)
The size of a picture. 6000 px wide means very large and sharp.
Render
A realistic image of a space, made in Enscape, V-Ray, D5 or Lumion.
Reference marker
A small red dot placed at the same four spots in CAD and SketchUp so the two can be lined up.
Exploded view
The 3D view pulled apart into layers floating above each other.
Escape route (egress)
The path people take to get out of the building in a fire.
Travel distance
The longest distance anyone should have to walk to reach a fire exit. The fire code sets the limit.

03Your CAD job, step by step

You'll add the PRES layers to a copy of the final layout, draw simple labelled shapes on them, check them and save a DXF. Work through the steps in order. Each one says what to do, why it matters and how to check it.

1

Make a working copy

Do
Open the final layout and use SAVEAS to save it as acko-layout-PRES.dwg. Work only in this copy.
Why
You're adding things just for the presentation. The real drawing stays untouched.
Check
The title bar shows the new file name.
2

Create the PRES layers

Do
Type LAYER and press Enter. In the Layer Properties Manager, click New Layer and type each name exactly:
PRES-PLATE PRES-CORE PRES-STAIR PRES-FIRE-EXIT PRES-FIRE-ROUTE PRES-STREET PRES-NBHD PRES-TS PRES-ROOM PRES-REF, plus PRES-DD and PRES-SITE if asked. Give them any bright colours so you can see them.
Why
The computer finds things by layer name, the way a postman finds a house by its address. One wrong letter and it won't find it.
Check
Every name is in capitals, starts with PRES- and uses hyphens, not spaces or underscores.
3

Learn the one skill you'll use most: closed shapes

Do

First make the right PRES layer current (pick it in the Layer drop-down on the Home tab). Then draw the shape in one of two ways:

  1. By hand: type PLINE, click round the shape, then type C and press Enter. C means Close.
  2. Faster: type BO (BOUNDARY). Set Object type to Polyline, click Pick Points, click inside the area, press Enter. AutoCAD traces the edges for you on the current layer.
Why
Only closed shapes can be filled with colour and measured.
Check
Select the shape and press Ctrl+1. The Properties palette must say Closed: Yes.
Think of it likeA fence around a field. If the fence has even a tiny gap, the colour "leaks out" and the computer can't tell how big the field is. Ends that only touch still count as a gap; the shape must be marked closed.
4

Floor outline PRES-PLATE

Do
Draw one closed shape around the usable floor, along the inside face of the outer wall or glass.
Why
This is the edge of the "city". It gives the total floor area and is the outline that draws itself at the start of the presentation.
Check
Only one shape on this layer. Closed.
5

Core and fire stairs PRES-CORE PRES-STAIR

Do
On PRES-CORE, draw closed shapes round the core, lifts, toilets, shafts and AHU rooms, each with a label inside: CORE, LIFTS, WC, SHAFT, AHU. On PRES-STAIR, draw one closed shape round each fire stair with a label: STAIR A, STAIR B and so on.
Why
These are the fixed parts of the building that everything else is planned around.
Check
Every label sits inside its own shape.
6

Main walkways PRES-STREET

Do
Draw closed shapes for Main Street and each lane (the main walkways). Label them MAIN STREET or LANE.
Why
In the story, the fire escape routes become the main walkways. These shapes are those walkways.
Check
Streets touch the neighbourhood shapes along their edges but don't overlap them.
7

Neighbourhoods PRES-NBHD

Do
Draw one closed shape for each neighbourhood. Run its edge along the edge of the street, not the middle of the street. Put a label inside with the ID and the name: N1 INDIRANAGAR.
Why
This is the heart of the concept. From these shapes the presentation colours each neighbourhood, shows its name, works out its area and counts what's inside it.
Check
Six shapes, no overlaps, one label inside each. IDs N1 to N6 match the names list from the project lead.
Think of it likeA plot of land with a fence round it and a name board inside. The fence is the closed shape, the name board is the label.
8

Town Square PRES-TS

Do
Draw closed shape(s) around the shared areas (reception, café, town hall, boardroom, wellness) and label them TOWN SQUARE.
Why
It's highlighted as the one place every team shares.
Check
It doesn't overlap the neighbourhoods or the core.
9

Rooms you can click PRES-ROOM

Do
Draw a closed shape for every room or space that should open a render, with a keyword label inside. Use only these keywords, spelled exactly:
WORKSTATIONS CABIN TOUCHDOWN FOCUS BOOTH MEETING HUDDLE PANTRY RECEPTION TOWNHALL BOARDROOM CAFE WELLNESS.
Add the seat count after meeting rooms: MEETING 8.
Why
When someone clicks this shape in the presentation, it opens the renders for that keyword.
Check
Keywords spelled exactly (CAFE without the accent). For desks, one WORKSTATIONS shape per desk cluster is enough.
TipMake PRES-ROOM the current layer, type BO, then click once inside each room. One click per room gives you a perfect closed shape.
10

Fire exits and escape routes PRES-FIRE-EXIT PRES-FIRE-ROUTE

Do

First the exits: on PRES-FIRE-EXIT, place a text EXIT A, EXIT B… with its insertion point in the middle of each exit door.

Then the routes: on PRES-FIRE-ROUTE, use PLINE and draw each route the way a person would walk out in a fire. Start clicking at the farthest desk in the zone, click at every turn, and make your last click exactly on the exit door. Don't close it.

Why
The order you click is the direction the animated arrows flow. Start at the exit by mistake and the arrows run backwards. The length is measured automatically and checked against the fire-code limit.
Check
Straight lines only, no cutting through furniture or walls. The last point sits on the exit door. At least one route per neighbourhood and one for the Town Square.
11

Four reference points PRES-REF

Do
Place four small circles: three at outer corners of the floor plate and one on a column far away from them. Label them REF-1 to REF-4. Write down which point is which and give the list to the SketchUp team.
Why
The SketchUp team puts red markers at the same four spots. Matching the four pairs lets us lay your CAD plan exactly on top of the 3D view.
Check
The four points are not all on one straight line.
Think of it likePinning a printed map onto a wall map. Once the pins at a few known places match, the whole map lines up.
12

Keep furniture as blocks and fill in the block map

Do
Don't explode furniture blocks. In block-map.xlsx, list each furniture block name and what it is (for example WS-1200x600 = workstation). Write "Yes" for things to count and "No" for things like chairs.
Why
The presentation counts the blocks inside each neighbourhood to write lists like "72 workstations, 6 focus pods".
Check
Click a desk and press Ctrl+1. Properties should say Block Reference, not Line.
13

Fill in the layer sheet

Do
In layer-sheet.xlsx, list each of your existing layers and what is on it (walls, glass, doors, columns, furniture, ceiling, text). Mark dimensions, hatches and title blocks as "hide".
Why
We restyle the drawing layer by layer, so it looks clean and consistent in the presentation.
Check
Every layer that has lines on it appears in the sheet.
14

Clean up and save as DXF

Do
  1. FLATTEN → type ALL, Enter → answer No to "remove hidden lines".
  2. XREF → right-click each reference → Bind → Insert.
  3. UNITS → Insertion scale: Millimeters.
  4. PURGE → Purge All, with Purge nested items ticked.
  5. AUDIT → Yes to fix errors.
  6. OVERKILL → select everything → OK. This removes duplicate lines.
  7. SAVEAS → Save as type: AutoCAD 2018 DXF (*.dxf) → name it acko-layout.dxf.
  8. Also PLOT a PDF of the same layout (DWG To PDF.pc3) named acko-layout.pdf.
Why
This makes the file flat, clean, complete and readable outside AutoCAD.
Check
Close and re-open the DXF. The PRES layers and shapes are all still there.

04Your SketchUp job, step by step

We don't need the SketchUp file itself. We need a set of pictures of the model, all taken from exactly the same camera, each with different parts switched on.

Think of it likeA photographer with a camera fixed on a tripod, photographing a stage set. Between shots, the crew takes some props away: one photo of only the floor, one with the walls, one with the furniture. Because the tripod never moves, the photos line up perfectly and can be stacked like sheets of tracing paper. That's exactly what we need from SketchUp.

The presentation uses that stacking for two effects. It builds the 3D view up layer by layer, and it pulls the layers apart for the exploded view. If even one picture is a few pixels off, the layers visibly jump, so the rules below are strict about the camera.

1

Make a working copy

Do
File → Save As → acko-axo-PRES.skp. Work only in this copy.
Why
You'll reorganise groups and tags. The design model stays safe.
Check
The new name shows in the title bar.
2

Organise the model into groups ("folders inside folders")

Do

Make one group for each neighbourhood, one for the Town Square and one for the building shell (slab, columns, core, façade). Inside each neighbourhood and the Town Square, make smaller groups for floor finishes, walls and glass, furniture, and ceiling. To make a group: select the objects → right-click → Make Group. Double-click a group to open it and make groups inside it.

Why
So we can switch whole neighbourhoods, or all the walls, on and off.
Check
Nothing is left loose inside a neighbourhood group; everything sits in one of its four smaller groups.
Model
├─ Shell                        tag SHELL
├─ N1 Indiranagar               tag NB-N1
│  ├─ Floor finishes            tag FLOOR
│  ├─ Walls and glass           tag WALLS
│  ├─ Furniture                 tag FURNITURE
│  └─ Ceiling                   tag CEILING   (if you have one)
├─ N2 … N6                      same pattern, tags NB-N2 … NB-N6
├─ Town Square                  tag TS, same four groups inside
├─ Streets                      tag STREET    (walkway floor finish, if any)
└─ Reference markers            tag REF       (step 4)
3

Create the tags and give each group its tag

Do
Open the Tags panel (Window → Default Tray → Tags). Click + to add: SHELL FLOOR WALLS FURNITURE CEILING STREET NB-N1 … NB-N6 TS REF. Then select a group, open Entity Info, and pick its tag. Big outer groups get the neighbourhood tag; the smaller groups inside get FLOOR, WALLS, FURNITURE or CEILING. Leave loose lines and faces Untagged.
Why
SketchUp hides something if its own tag or its outer group's tag is switched off. That lets us show, say, "only the walls" or "only Indiranagar" just by clicking eye icons.
Check
Click the eye next to NB-N1: all of Indiranagar disappears. Click the eye next to WALLS: the walls disappear everywhere.
4

Add the four red reference markers

Do
Using the CAD team's list, draw a small red disc or cube (about 300 mm) at each of REF-1 to REF-4, at floor level. Paint them pure red. Group them and tag the group REF.
Why
These are the "pins" that let us line up the CAD plan with your 3D pictures.
Check
The markers sit exactly on the same corners and column as in the CAD.
5

Set the camera, then don't touch it

Do
  1. Camera → Parallel Projection (it must show a tick).
  2. Camera → Standard Views → Iso, then use Orbit to reach the angle the design lead approves.
  3. Open the Scenes panel (Window → Default Tray → Scenes), click +, and rename the scene PRES-AXO.

From now on, don't orbit, pan or scroll-zoom.

Why
Every picture must come from exactly the same camera position.
Check
If you move the camera by accident, click the PRES-AXO tab to snap back. Scrolling the mouse wheel even once moves the camera.
6

Set the look

Do
In Styles → Edit → Background settings, untick Sky and Ground. Turn fog off (Fog panel: untick Display Fog). Turn shadows off (Shadows panel), except for the hero picture. Use the same style for every picture.
Why
A clean, see-through background lets the pictures stack. Shadows change between pictures and would look messy when layered.
Check
The background behind the model is plain white in SketchUp. The export makes it see-through in step 8.
7

Make one scene per picture

Do
Click the PRES-AXO tab. Switch tags on or off as in the table below, click + to add a scene, and rename it after the picture. Repeat for each picture. In each scene's details, keep Camera Location and Visible Tags ticked.
Why
Re-exporting after a design change then takes a few clicks instead of an afternoon.
Check
Clicking between your scene tabs never moves the model on screen; only parts appear and disappear.

"Only" means: all the neighbourhood and Town Square tags stay on (except in the zone pictures), plus the one part listed; every other part is off.

8

Export the pictures

Do
File → Export → 2D Graphic → choose PNG → click Options: untick Use view size, set width to 6000, tick Anti-alias, tick Transparent background. Then click each scene tab in turn, export, and name the file exactly as in the table.
Why
6000 px stays sharp even when we zoom into one neighbourhood on a big screen.
Check
Don't open, close or resize panels or the SketchUp window while exporting. The picture's height follows the window's shape, so a resized window gives a different height.
9

Check the pictures

Do
Check that every picture has exactly the same size in pixels. On Windows: right-click → Properties → Details. On Mac: Get Info → More Info. For a final check, open two pictures as layers in Photoshop and switch the top one on and off: a column should not move at all.
Why
Same size and no movement means the stacking will be perfect.
Check
The see-through areas show as a checkerboard in Photoshop.

05Renders: light and dark

When someone clicks a room in the presentation, a viewer opens with that room's two renders and a slider in the middle. Drag the slider and the light version blends into the dark one.

Think of it likeBefore-and-after photos of a renovation. If the photographer stands somewhere else for the "after" shot, the slider jumps instead of blending smoothly.

The rules, simply

  1. Same camera for both versions. Save the view in your render tool (an Enscape view, a SketchUp scene for V-Ray, a D5 view or a Lumion photo). Render the light version and the dark version from that saved view. Change only materials and lighting.
  2. Same size for every render, for example 3000 × 1688 px (16:9) for all of them.
  3. JPG, high quality (85–90), with no text, logos or watermarks on the image.
  4. One pair per type of space is enough. All meeting rooms can share one pair. If one neighbourhood's room looks different, give it its own pair with the ID in front: n1-meeting-light.jpg.
  5. Name the files exactly, in lower case: desk, cabin, touch, focus, booth, meeting, huddle, pantry, reception, townhall, board, cafe, wellness, each followed by -light.jpg and -dark.jpg. For example: huddle-light.jpg and huddle-dark.jpg.

Until real renders arrive, the presentation shows a simple sample picture for each space. As soon as a correctly named file is added, it replaces the sample.

07Questions juniors usually ask

Do the colours and line weights on the PRES layers matter?
No. We restyle everything. Pick bright colours that help you see what you've drawn.
Can I send a DWG instead of a DXF?
Please don't. DWG is a closed format we can't open. A DXF holds exactly the same drawing.
My AutoCAD doesn't list "AutoCAD 2018 DXF".
Use AutoCAD 2013 DXF instead. Avoid the very old "R12" option.
The neighbourhood edges aren't decided yet. What do I draw?
Draw the streets, core, stairs and Town Square only. We'll propose the neighbourhood shapes from what's left and send them back for approval.
Do I need a shape around every desk?
No. One WORKSTATIONS shape per desk cluster, or one around the whole desk area, is enough. Desks are counted from the blocks.
How do I know which desk is the "farthest" for a fire route?
Pick the desk that would take longest to walk from to any exit, following the aisles. If you're not sure between two, draw both; the presentation shows the longest. The fire consultant's plan helps too.
Where does the travel-distance limit come from?
From the fire code (NBC) and the fire consultant. Ask the project lead, and note it in notes.xlsx.
I moved the SketchUp camera after exporting a few pictures. Now what?
Click the PRES-AXO tab, then re-export all the pictures, not just the remaining ones, so every picture matches.
The PNG files are huge.
That's expected at 6000 px. Share them through a drive link rather than email.
Can I just send the SketchUp model instead of pictures?
The pictures are what we need; we can't open SketchUp files outside SketchUp. A 3D export (.dae or .glb) is a nice extra if there's time.
Who do I ask when I'm stuck?
The project lead. Send a screenshot of what you see. It's usually a quick fix from the table in section 06.

08Before you send: final check

Tick these off before handing over. The full lists are in sections 2.9 and 3.8 of the handover spec.

CAD

  • File is acko-layout.dxf, saved as AutoCAD 2018 DXF
  • Units in millimetres, everything flat
  • All PRES layers present, names spelled exactly
  • Every shape closed (Ctrl+1 shows Closed: Yes)
  • One label inside every neighbourhood, Town Square and room
  • Fire routes start at the far desk and end on the exit door
  • REF-1 to REF-4 placed, list given to SketchUp team
  • Furniture still in blocks; block map and layer sheet filled
  • PDF plot of the same layout included

SketchUp

  • Camera → Parallel Projection is ticked
  • Scene PRES-AXO saved; camera never moved after
  • Groups and tags organised as in step 2
  • Red REF markers at the same points as in CAD
  • Sky, ground and fog off; shadows only on the hero picture
  • All PNGs 6000 px wide, same height, see-through background
  • File names exactly as in the step 7 table

Renders

  • Light and dark from the same saved view
  • All renders the same size, JPG, no text
  • Names like meeting-light.jpg, lower case
