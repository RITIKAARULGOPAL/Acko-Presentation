01Naming rules and IDs

One set of names for the drawing, the images, the renders and the sheets, so every file lands in the right place without anyone renaming it.

1.1Rules

  1. Lowercase, hyphens, no spaces. Plain letters only: cafe, not café. No (1) or copy in names.
  2. File names never change between issues. A re-export replaces the file of the same name, and the presentation picks it up with no code changes.
  3. The revision and date go on the folder, not the files: acko-inputs-tf03-2026-10-12.
  4. Dates as YYYY-MM-DD. "5.10.26" can be read as 5 October or 10 May.
  5. One readme.txt per issue: revision, date, what changed since the last issue, who exported.
Where this differs from the handover spec v1.1These names replace the older ones: neighbourhoods are n01–n06 (not N1–N6), the Town Square is now the shared spaces (PRES-SHARED, axo-zone-shared.png), the south cut-outs are terraces, and SketchUp exports are 8000 px wide.

02CAD: the DXF

Your working layers stay exactly as they are. The presentation reads the plan, rooms and furniture from them, and a few PRES layers drawn on top tell it where the zones, routes and terraces are.

Lesson from test fit 02The zones and egress routes came as copies in separate panels above and below the plan, so they had to be shifted back by measured distances. For the actuals, draw them on the PRES layers directly over the plan, in the same position, and keep only this floor in model space.

2.4Export

  • AutoCAD 2018 DXF, units millimetres
  • Model space holds only this floor, at Z = 0
  • Xrefs bound; PURGE, AUDIT and OVERKILL run
  • Saved as acko-layout.dxf, then zipped
  • Vector PDF plot as acko-layout.pdf
  • Block map filled in

03SketchUp images

The 3D views are built from images taken from one fixed camera, each with different tags switched on. Because every image lines up exactly, they can be stacked, pulled apart for the exploded view and highlighted one zone at a time.

3.1Tags

SHELL · FLOOR · WALLS · FURNITURE · CEILING · NB-N01 … NB-N06 · SHARED · TERRACE · REF. Each zone group carries its zone tag; the groups inside it carry the category tags.

3.3Settings

  • One saved scene, PRES-AXO, for every full-floor image
  • Camera → Parallel Projection (never perspective)
  • PNG, 8000 px wide (the floor is about 7:1)
  • Transparent background; sky and ground off
  • All full-floor images exactly the same pixel size
  • Shadows only on axo-full.png
  • Same 4 REF markers as in the DXF
  • Optional: acko-model.glb or .dae

04Renders

Clicking a space opens its light and dark renders, with a slider that wipes from one to the other. The two have to line up exactly for the slider to work.

  • Light and dark from the same saved camera
  • JPG, quality 85–90, sRGB
  • 2400–3000 px wide, all 16:9
  • No text, logos or watermarks

Name each pair <key>-light.jpg and <key>-dark.jpg. One pair per key is enough. To show a different version in one neighbourhood, prefix its ID: n03-huddle-light.jpg.

06To confirm, and the final check

Decisions taken while building on test fit 02. Tick them, or note what should change, in readme.txt.

6.1To confirm

  • Neighbourhoods are numbered 01 to 06 from west to east (zones 4, 8, 7, 3, 2 and 1 in test fit 02)
  • Shared spaces are the café and dining area, the lobby by the lifts, and the west and east receptions. Are the terraces shared spaces too?
  • The 35-seat boardroom stays with Neighbourhood 02
  • The twelve 4-seat planter tables count as workstations (651 in total)
  • Which neighbourhood gets the rooms outside every zone: the west executive cabin, one huddle, two phone booths and the server room
  • The square by the lifts marked "Cutout above": an opening, or something else?
  • Teams under each neighbourhood: the real teams, or none
  • The brief numbers for the sharing-out table

6.2Before you send

  • Folder named acko-inputs-tfNN-YYYY-MM-DD, with readme.txt
  • File names exactly as listed: lowercase, hyphens, no spaces, no (1)
  • DXF 2018 in mm, only this floor in model space
  • PRES layers drawn over the plan, not in separate panels
  • Every PRES shape closed, one label inside each
  • Egress routes run from the far point to the stair door
  • REF-1 to REF-4 identical in CAD and SketchUp
  • All full-floor PNGs the same pixel size, transparent
  • Light and dark renders from the same camera
  • Sheets filled in, using IDs n01–n06
What happens nextWe run the DXF through the pipeline, check the zones, routes and counts against your drawing, and send back the updated presentation with a short list of anything missing or unclear.
